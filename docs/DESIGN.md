# 크랙 페인터 2 설계

2.0은 1.x 코드를 하나도 이어받지 않고 처음부터 다시 쓴다. 1.x는 다른 사람이 만든 Crack Scene Painter의 흐름을 따라 만들었다. 같은 흐름에서 AI가 태그를 처음부터 지어내고, 인물 외형은 따로 적어 두는 구조였다. 2.0은 NAI 자동화 프로젝트의 방식을 중심으로 다시 설계한다.

## 원칙

1. **인물은 작품 JSON에서 온다.** 오토세이버 대기열 JSON(`작품.json`, `작품_V5.json`)이나 spec JSON을 불러오면 인물마다 외형·의상·캐릭터 부정·감정 블록·배경 블록이 그대로 들어온다. 삽화 속 인물은 감정 이미지와 같은 태그로 그려진다.
2. **베이스는 작품 것을 그대로 쓴다.** 대기열 JSON에 들어 있는 basePrompt·baseNegativePrompt를 고치지 않고 쓴다. AI는 베이스를 건드리지 못한다.
3. **AI는 연출만 정한다.** 누가 나오는지, 감정(17 + NSFW 12), 장소(낮·밤·실내·섹스·직접), 샷·각도, 인물별 표정·시선·자세, 둘 사이의 상호작용만 고른다. 외형·의상·화풍 태그는 결과에서 지운다.
4. **가이드 규칙은 코드가 지킨다.** AI가 실수해도 생성 전에 고친다.
   - 그림은 가로(1216×832). 서 있는 전신(`full body` + `standing`)은 `cowboy shot`으로 바꾼다.
   - 소품은 작품 외형·의상 태그나 사용자가 쓴 장면에 있는 것만 남긴다.
   - 어려 보이는 태그는 모든 칸에서 지운다.
   - 캐릭터 부정에 `beard`가 없으면 넣는다(작품에서 수염이 있는 인물은 예외).
   - NSFW는 작품 JSON에 섹스 세트가 있는 인물(=성인으로 만든 인물)만 허용한다.
5. **원하는 장면을 직접 쓸 수 있다.** 한국어로 쓰면 AI가 연출로 옮기고, AI를 안 쓰면 인물·감정·장소를 직접 골라 그린다. 혼자 나오는 장면은 그 인물의 실제 감정 블록을 그대로 쓴다.

## 흐름

```
답변 아래 [삽화] → 오른쪽 인스펙터
  ├ 원하는 장면(선택) ─┐
  ├ 앞뒤 대화(API) ────┼→ AI 연출 JSON → 규칙 검사 → 칸별 프롬프트 → NAI
  └ 작품 인물 카드 ────┘
```

## 모듈

| 파일 | 역할 |
|---|---|
| `tags.js` | 태그 문자열 분해(가중치·랜덤 문법 보존), 정규화, 토큰 추정 |
| `works.js` | 작품 JSON 읽기(대기열 v3 · spec), 인물 카드 만들기 |
| `rules.js` | 가이드 규칙(가로 구도, 소품, 연령, beard, NSFW) |
| `direct.js` | AI 지시문, 연출 JSON 검사 |
| `compose.js` | 연출 → 베이스·캐릭터 칸, V4.5 512 예산 줄이기, V5 변환 |
| `ai.js` | Gemini · Claude · OpenAI API, ChatGPT 웹 중계 |
| `relay.js` | chatgpt.com 쪽: 요청문 넣기 → 답 JSON 돌려주기 |
| `nai.js` | NAI 요청 본문, 응답 이미지 꺼내기 |
| `crack.js` | 크랙 메시지 찾기, 메시지 API |
| `db.js` | 설정(GM), 삽화(IndexedDB), 1.x 기록 옮기기 |
| `ui/*` | 아이콘(직접 그림), 인스펙터, 작업실(작품·갤러리·설정) |

## 1.x에서 옮기는 것

- 키: `cp_secrets_v1`의 NovelAI 토큰, Gemini 키
- 삽화: IndexedDB `crack-painter`의 이미지와 기록. 메시지 ID로 다시 연결되는 것은 채팅에 다시 붙고, 아니면 갤러리에만 남는다.
